# Competitive positioning

Use these talking points; do not disparage named competitors.

## Versus generic iPaaS

Northstar Cloud is sold as an agent-ready automation layer. Lead with Agent Fabric and Agentforce connectivity, not connector count.

## Proof points

- Native A2A and MCP registration so Agentforce can call internal knowledge without a custom Apex callout per use case.
- Enterprise SKU required when the customer needs SSO, audit logs, or a sandbox.
- Discount only through Deal Desk; never match a competitor quote on the first call.

## Landmines

Do not discuss unannounced roadmap. If asked about on-prem runtime, say it is available only on Enterprise with a services engagement, then offer a solution architect.
